<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| visitor browser → ContactForm | Untrusted user input (naam, email, bericht, onderwerp) is collected client-side |
| ContactForm → Web3Forms API | Untrusted input crosses to the external `https://api.web3forms.com/submit` endpoint over HTTPS |
| Web3Forms API response → DOM | The API JSON response returns into the page and could be rendered |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-2-01 | Spoofing | ContactForm submission | medium | mitigate | Honeypot `botcheck` checkbox (display:none, tabindex=-1, aria-hidden) + Web3Forms server-side spam filter. Honeypot-only is the accepted v1 posture (D-03); visible CAPTCHA is deferred. |
| T-2-02 | Tampering | Form result rendering (success/error) | high | mitigate | Success/error copy is ALWAYS a static string from `nl.contact`; NEVER echo `json.body.message` or any user input into the DOM. `grep json.body.message` must be 0. (RESEARCH §Security Domain, UI-SPEC State 6/7.) |
| T-2-03 | Info disclosure | Web3Forms access key in client HTML | low | accept | The access key is a public client-side identifier by design (Web3Forms), not a secret. Destination email lives on the Web3Forms side. No PII/secret in repo. |
| T-2-04 | Tampering | Open redirect via `redirect` field / `?type=` param | medium | mitigate | `redirect` hidden input uses only a hardcoded absolute value; `?type=` is validated against the fixed option set with a `CSS.escape` guard before use — unknown values ignored, never reflected. |
| T-2-05 | Spoofing/Repudiation | Fake success with placeholder key | high | mitigate | With the sentinel key the form must NOT show success — the API error path (State 7) handles the invalid key; a `console.warn` documents the non-functional state (D-02). No success state is ever faked. |
| T-2-SC | Tampering | npm/pip/cargo installs | n/a | accept | No new packages this phase (Web3Forms is an external HTTP API only; RESEARCH §Package Legitimacy Audit = N/A). No install task exists; gate does not fire. |
</threat_model>
