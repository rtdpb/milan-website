## Spacing Scale

Declared values (all multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| --space-xs | 4px | Icon-to-label gaps, badge internal padding |
| --space-sm | 8px | Inline button padding (vertical), list item row gaps |
| --space-md | 16px | Default card inner padding (horizontal edge), paragraph gap |
| --space-lg | 24px | Card inner padding (vertical), component margin-bottom |
| --space-xl | 32px | Section inner top/bottom padding (mobile) |
| --space-2xl | 48px | Section padding (tablet) |
| --space-3xl | 64px | Section padding (desktop), hero vertical breathing room |
| --space-4xl | 96px | Major section breaks between full-width bands |
| --space-5xl | 128px | Page-level hero / dark-band vertical padding (desktop) |

Exceptions:
- Touch targets (mobile nav toggle, social icon) must be at least 44×44px per WCAG 2.5.5 — use padding to reach 44px even when the visual element is smaller.
- The "bekend van" press strip: 20px vertical padding (between the 8 and 24 standard steps) — slim by design; token `--space-press-strip-y: 20px`.
- USP row in hero: 12px column gap (`--space-usps-gap: 12px`) — tighter than sm to keep the row compact on mobile.

**Source:** D-04, D-07 (CONTEXT.md); standard 8-point scale; mobile-first exceptions noted.

## Typography

### Type Scale

| Role | Size | Weight | Line Height | Font Stack | Usage |
|------|------|--------|-------------|------------|-------|
| Display | 56px (desktop) / 40px (tablet) / 32px (mobile) | 600 (semibold) | 1.1 | `var(--font-display)` — serif | Hero H1 "Je bedrijf schalen, zonder jezelf te verliezen" |
| Heading | 36px (desktop) / 28px (tablet) / 24px (mobile) | 600 (semibold) | 1.2 | `var(--font-display)` — serif | Section headings (Samenwerken, Testimonials, Recente artikelen, etc.) |
| Subheading | 22px | 500 (medium) | 1.3 | `var(--font-display)` — serif | Card titles, story pull-quote emphasis |
| Body | 17px | 400 (regular) | 1.6 | `var(--font-body)` — grotesque sans | Running body copy, card descriptions |
| Label / Eyebrow | 13px | 600 (semibold) | 1.4 | `var(--font-body)` — grotesque sans | Section eyebrow labels ("01 START", press-strip label, placeholder badges), nav items, footer nav |
| Meta / Caption | 13px | 400 (regular) | 1.4 | `var(--font-body)` — grotesque sans | Article card date/read-time, attribution, footer legal |
| CTA / Button | 15px | 600 (semibold) | 1.0 | `var(--font-body)` — grotesque sans | Button labels (Contact, Schrijf je in, Plan kennismaking, etc.) |

### Weights used
Exactly 2 weights: **400 (regular)** + **600 (semibold)**. The display heading at 600 reads as editorial weight for a serif — no 700/bold needed. Medium (500) used for subheadings only if the chosen serif renders 600 too heavy at 22px; otherwise collapse to 600.

### Notes
- Letter-spacing on eyebrow/label: 0.08em uppercase or 0.04em mixed-case — creates the editorial "datum / chapter" feel.
- Heading line-height tightens to 1.1 at display size (hero H1) and relaxes to 1.2 for section headings — natural visual rhythm.
- Body line-height 1.6 (generous) for legibility at 17px; long-form story copy especially benefits.
- Max-width of body text columns: 680px (reading measure) — never full-width on desktop.
- The dark personal story band uses the same type scale but all text in white/near-white; no separate dark-mode scale needed.

**Source:** D-13 (CONTEXT.md); Sevora-inspired editorial character; 4 sizes declared (Display, Heading, Body, Label) plus Subheading/Meta/CTA refinements within the 4-tier framework.

## Color

### Palette

| Token | Hex | Role |
|-------|-----|------|
| `--color-bg` | `#FAF8F4` | Off-white/cream — dominant background (60%) |
| `--color-surface` | `#F0EDE7` | Secondary surface — card backgrounds, light section variants (30%) |
| `--color-text` | `#1A1A18` | Near-black — primary text |
| `--color-text-secondary` | `#5A5A52` | Mid-grey — secondary text, captions, placeholders |
| `--color-border` | `#E2DDD6` | Subtle divider/card border — cream-grey |
| `--color-accent` | `#FFDD11` | Yellow — single accent, restrained (10%) |
| `--color-accent-dark` | `#C9AC00` | Yellow darkened 20% — hover state for accent elements only |
| `--color-dark-band` | `#111110` | Near-black — full-width dark band backgrounds |
| `--color-dark-text` | `#F5F2EC` | Off-white — text on dark bands |
| `--color-dark-surface` | `#222220` | Dark card background — testimonial accent card on dark band |
| `--color-destructive` | `#C0392B` | Error/destructive — form validation errors only |

### 60 / 30 / 10 Split

- **60% dominant** — `#FAF8F4` off-white/cream: page background, hero left panel, section surfaces, the newsletter section, footer.
- **30% secondary** — `#F0EDE7` and `#111110` combined: light card backgrounds (Samenwerken cards, article placeholder cards) + 1–2 full-width dark bands (personal story band + footer or as design warrants). Dark band counts as structural "secondary" rather than accent.
- **10% accent** — `#FFDD11` yellow, strictly reserved for the elements listed below.

### Accent reserved for (explicit list — never general UI)

1. **Hero photo yellow backdrop** — the photograph itself; no CSS tinting needed but the yellow reads as the first signature moment.
2. **Primary CTA button** — background on the "Contact" button in the hero (and matching CTAs elsewhere). Text on yellow button: `--color-text` near-black for contrast.
3. **Active / current nav underline** — a 2px yellow underline on the active nav item (not all nav items; only the active state).
4. **One deliberate highlight in the personal story section** — e.g., a 4px left-border accent on a pull-quote, or the section eyebrow label background. One usage, not all headings.
5. **Keyboard focus ring** — `outline: 2px solid #FFDD11` for all interactive elements (not a new usage of yellow for sighted users, but doubles the focus ring in brand colour).

Yellow is explicitly NOT used for: body text, card backgrounds, dividers, section backgrounds, icon fills (unless the design warrants a single exception at review time).

### Dark bands

The personal story section ("Waarom ik nu mijn lessen deel") is a full-width dark band using `--color-dark-band` (#111110) with all text in `--color-dark-text`. Testimonials: the mosaic may include one larger card in `--color-dark-surface` (#222220) as a visual anchor — all other testimonial cards use light surfaces.

**Source:** D-01, D-02, D-03 (CONTEXT.md); neutral-only palette with single yellow accent.

## Interaction Contracts

### Button Variants

| Variant | Background | Text | Border | Hover | Disabled |
|---------|-----------|------|--------|-------|---------|
| Primary | `#FFDD11` | `#1A1A18` | none | bg `#C9AC00`, slight scale 1.02 | opacity 0.5, cursor not-allowed |
| Secondary / Ghost | transparent | `#1A1A18` | 1px `#1A1A18` | bg `#1A1A18`, text white | opacity 0.5, cursor not-allowed |
| Ghost on dark | transparent | `#F5F2EC` | 1px `#F5F2EC` | bg `#F5F2EC`, text `#1A1A18` | opacity 0.5, cursor not-allowed |

Button sizing: `height: 48px`, `padding: 0 24px`, `border-radius: 8px`, `font-size: 15px`, `font-weight: 600`, `letter-spacing: 0.02em`.

Minimum touch target on mobile: 44px height — use padding to compensate.

### Disabled / Placeholder CTA Pattern (HOME-10)

Every CTA whose destination is unknown or deferred:
1. `aria-disabled="true"` on the element.
2. `tabindex="-1"` (removes from tab order) unless it must be focusable to be discoverable — in that case keep in tab order with an `aria-label` explaining it is a placeholder.
3. CSS: `cursor: not-allowed; opacity: 0.5;` — or a `[Binnenkort beschikbaar]` label appended visually.
4. Code comment `<!-- TODO: wire destination when available — [REASON/PHASE] -->`.
5. Documented in phase PLAN.md task "Disabled CTAs inventory".

No JavaScript click handlers on disabled elements. No fake success states. No `href="#"` without the disabled treatment.

### Navigation — Mobile

- Hamburger icon (three lines) at 44×44px touch target, top-right.
- On toggle: full-height right-to-left slide-in overlay, `background: var(--color-bg)`, z-index above content.
- Close button (×) at same position. Focus trapped in nav while open.
- Same nav items as desktop, same disabled states.
- Animation: `transform: translateX(100%) → translateX(0)`, duration 240ms, ease-out. Respects `prefers-reduced-motion` (instant show/hide if reduced-motion).

### Scroll-Reveal Animations

- Pattern: `opacity: 0 → 1` + `transform: translateY(16px) → translateY(0)`, duration 400ms, ease-out.
- Trigger: element enters viewport (IntersectionObserver, threshold 0.15).
- Applied to: section headings, card grids (stagger 80ms per card), the story section content.
- `prefers-reduced-motion: reduce` → skip all transforms and opacity transitions; elements are visible immediately.
- No heavy parallax. No scroll-jacking.

### Form Input Focus States

- Focus ring: `outline: 2px solid var(--color-accent)` with `outline-offset: 2px`.
- Applied to all interactive elements globally (keyboard navigation a11y requirement, FND-06).

## Accessibility Contract (FND-06)

- Semantic HTML landmarks: `<header>`, `<main>`, `<nav>`, `<footer>`, `<section aria-labelledby>` for each homepage section.
- All images have meaningful `alt` text (see Image Pipeline Contract above). Decorative images: `alt=""`.
- Color contrast: `--color-text` (#1A1A18) on `--color-bg` (#FAF8F4) → contrast ratio ~18:1 (AAA). Yellow (#FFDD11) on near-black (#1A1A18) → ~8:1 (AA large). Yellow as bg for primary button with near-black text → ~8:1 (passes AA for normal text at 15px bold).
- Focus visible on all interactive elements (FND-06): `outline: 2px solid var(--color-accent)` with 2px offset.
- Skip-to-content link: `<a href="#main-content" class="skip-link">` visually hidden, shown on focus.
- Disabled nav/CTA elements: use `aria-disabled="true"` not `disabled` attribute (keeps them discoverable by screen readers with appropriate labeling). Include `aria-label` clarifying placeholder status.
- Reduced-motion: all animations gated on `prefers-reduced-motion: no-preference`.
- Form: explicit `<label>` elements (not placeholder-only). `autocomplete` attributes on name/email fields.
