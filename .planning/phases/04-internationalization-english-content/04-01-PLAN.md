<assumption_delta_decision>
- **Singular→plural transition:** one locale (`nl`) becomes two (`nl`, `en`); the now-primary noun is **the active locale — a parameter, with `nl` as the default**.
- **Decision: promote.** Generalize the copy source from the direct `import { nl }` to `getStrings(Astro.currentLocale)` everywhere, rather than adding `en` alongside a still-hardcoded `nl`. Rationale: a single locale-parameterized path means a future 3rd locale needs no re-architecture — only a new strings file + one `locales` array entry.
- **Suggested (not required) invariant:** the `satisfies Record<Locale, Strings>` build constraint already guarantees every locale round-trips the same key shape; no runtime shape assertion needed.
</assumption_delta_decision>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| visitor → static HTML (GitHub Pages) | All content is build-time static; no server-side locale logic, no runtime user input on i18n paths. |
| language switch anchor | href is computed at build time from a fixed slug map — no user-supplied URL is ever reflected into the link. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-04-01 | Spoofing | Nav language switch href | low | mitigate | `getRelativeLocaleUrl` generates only in-site paths from a fixed `nlToEn`/`enToNl` map; no user input touches href construction (open-redirect impossible). |
| T-04-02 | Tampering | `en.ts` translated strings | low | accept | `en.ts` is a static TypeScript const rendered by Astro's auto-escaping; no runtime interpolation of untrusted data. No mitigation needed beyond existing escaping. |
| T-04-03 | Tampering | `nlToEn`/`enToNl` slug map lookup | low | mitigate | Map is keyed on a small fixed set derived from `Astro.url.pathname` (build-time), values fall back to `''`; no attacker-controlled key path. |

**No high-severity threat is introduced by this phase.** Phase 4 adds no new external API, no auth, no database, no payment surface, and no runtime user input — it localizes existing static pages and reuses the already-hardened Web3Forms contact form and Substack RSS unchanged. ASVS L1 block-on-`high` gate: PASS (nothing at `high`).
</threat_model>
