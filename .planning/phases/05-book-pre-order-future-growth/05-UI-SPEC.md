## New UI Surfaces — Detailed Contracts

### 1. Book Page (`/boek` NL + `/en/book` EN)

**Layout pattern:** Follows the existing editorial page template (`coaching.astro`, `spreker.astro`, `mijn-verhaal.astro`). One dark feature band maximum. Light sections bookend the dark band.

**Section order:**

| # | Section | Variant | Notes |
|---|---------|---------|-------|
| 1 | Hero / intro | `SectionWrapper variant="default"` (light) | Eyebrow + H1 + 2–3 body paragraphs + CTA group |
| 2 | (Optional) dark teaser band | `SectionWrapper variant="dark"` | Near-black (`--color-dark-band`); honest statement about the book; exactly 1 per page |
| 3 | Interest capture | `SectionWrapper variant="default"` (light) | Dual capture block — Substack primary + Web3Forms secondary |

**Hero section spec:**
- Eyebrow: `--text-sm`, semibold (600), `--font-body`, letter-spacing 0.08em, uppercase. Text: "Binnenkort" (NL) / "Coming Soon" (EN). No yellow accent on eyebrow in the light hero (reserve for dark band only).
- H1: `--text-4xl` to `--text-5xl` fluid, weight 300–400, `--font-display`. No yellow underline or decoration.
- Body: 2–3 paragraphs, `--text-base`, weight 400, `--font-body`, line-height 1.6. Max-width `--content-width` (1024px) constrained to 720px prose width.
- CTA group: stacked vertically on mobile (gap `--space-md`), horizontal row on ≥768px (gap `--space-md`). Contains the Substack redirect button as primary CTA (see §Interest Capture).

**Dark teaser band (if used):**
- Background: `--color-dark-band` (#111110)
- Text: `--color-dark-text` (#F5F2EC)
- Optional accent: 4px left border on eyebrow in `--color-accent` — maximum once on this band
- No purchase button in this band (honesty rule D-01, D-03)
- Padding: `--section-padding-y` (clamp `--space-xl` → `--space-5xl`)

**Checkout seam (D-03):**
- `TODO_BOOK_CHECKOUT_URL` constant in `src/config.ts`
- IS_SENTINEL guard: when sentinel is unreplaced, NO purchase/pre-order button is rendered anywhere on the page
- If IS_SENTINEL is false (real URL supplied): render `<Button href={checkoutUrl} variant="primary">` — label "Pre-order" (NL: "Pre-order" or "Bestel") in a dedicated section
- Never render a disabled `<span>` with "Pre-order" copy — that would set a false expectation; omit the block entirely when no real URL exists

### 3. Sticky CTA (`StickyCTA.astro`)

**Concept:** A fixed-bottom bar revealing the primary contact CTA when the hero/page CTA scrolls out of view. Subtle, non-intrusive, premium. No pop-up, no modal, no exit-intent.

**Dimensions and layout:**
- Position: `fixed`, `bottom: 0`, `left: 0`, `right: 0`
- Z-index: `90` — below nav header (`z-index: 100`) and mobile nav panel (`z-index: 200`)
- Bar height: auto — driven by `padding-block: var(--space-md)` (16px × 2 = 32px min-height)
- Background: `--color-bg` (#FAF8F4) — matches page background, premium and clean
- Top border: `1px solid var(--color-border)` (#E2DDD6) — subtle separator
- Inner container: `max-width: var(--max-width)` (1280px), `margin-inline: auto`, `padding-inline: var(--space-lg)` (24px) mobile → `var(--space-3xl)` (64px) at ≥768px
- Button alignment: `display: flex; justify-content: center` — centred single button

**Button inside sticky CTA:**
- Variant: `btn--primary` (yellow fill, near-black text)
- Label (NL): "Plan kennismaking" — same as existing coaching page primary CTA
- Label (EN): "Book a call"
- Height: 48px (min 44px), `padding-inline: var(--space-lg)`, `border-radius: var(--radius-md)`
- On click: fires `window.plausible('Sticky CTA: Click')` before navigation; `typeof window.plausible === 'function'` guard required

**Visibility logic (IntersectionObserver):**
- Observer watches the hero's primary CTA element (`id="hero-cta"` on the hero anchor)
- When hero CTA exits viewport (`!entry.isIntersecting`): sticky CTA becomes visible
- When hero CTA re-enters viewport: sticky CTA hides
- Initial state: `hidden` attribute on root element, `aria-hidden="true"` (invisible, not in tab order)
- Visible state: `hidden` removed, `aria-hidden="false"`

**Entrance animation:**
- Default (motion-ok): `transform: translateY(100%)` → `translateY(0)`, transition `var(--duration-base)` (300ms) `var(--ease-out)` cubic-bezier(0.16, 1, 0.3, 1)
- `prefers-reduced-motion: reduce`: transition set to `none` — bar appears/disappears instantly with no slide

**Mobile behaviour:**
- On mobile (`< 768px`): same fixed-bottom behaviour; `padding-inline: var(--space-lg)` (24px)
- Button spans near full width on mobile: `width: 100%; max-width: 360px`
- On tablet/desktop (≥768px): button is centred with auto width (not full-width)

**Dismissability:** None — the sticky CTA does not have a dismiss/close button. It hides automatically when the user scrolls back to the hero CTA. This matches the premium, non-intrusive brief (D-07). A close button would add UI chrome inconsistent with the restrained design.

**Pages where StickyCTA is included (Phase 5 scope):**
- Homepage (`/`, `/en/`) — primary target (long scroll)
- Book page (`/boek`, `/en/book`) — long teaser page
- Supporting pages (coaching, spreker, mijn-verhaal): out of scope for Phase 5; may extend in a later phase if analytics warrant it

**Plausible event:** `'Sticky CTA: Click'` — fires on click before `href` navigation. Register this goal in the Plausible dashboard as a Custom Event Goal (exact string match required).
