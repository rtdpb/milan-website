## Interaction Contracts

### Newsletter Signup Redirect (D-01/D-05)

1. User focuses email field — focus ring: `outline: 2px solid #FFDD11; outline-offset: 2px; border-color: #FFDD11` (carried from existing `.newsletter__input:focus-visible`)
2. User types email — no JS validation until submission attempt
3. User clicks/activates submit anchor (enabled state) — browser opens `${TODO_SUBSTACK_URL}/subscribe` in new tab; original page remains (no navigation away)
4. No on-site success state — success is on Substack's hosted page
5. If `TODO_SUBSTACK_URL` is sentinel: submit is `aria-disabled`, `pointer-events: none` — click/tap does nothing; AT reads "Aanmelden is binnenkort beschikbaar via Substack."

### "Lees verder" Card Link (enabled)

1. Renders as `<a>` with `target="_blank" rel="noopener noreferrer"`
2. Hover: no opacity change; `text-decoration: underline` to signal active link
3. Focus: `outline: 2px solid --color-accent; outline-offset: 2px`
4. Opens Substack post in new tab

### "Alle artikelen" Link (enabled)

1. Renders as `<a>` with `target="_blank" rel="noopener noreferrer"`
2. Hover: arrow glyph (`→`) translates right by 4px via `transform: translateX(4px)` with `transition: transform 150ms ease-out`
3. Focus: `outline: 2px solid --color-accent; outline-offset: 2px`
4. Opens Substack publication home in new tab

### Nav "Nieuwsbrief" Link (enabled)

1. Renders as internal `<a>` with `href="${BASE_URL}nieuwsbrief"`
2. When on `/nieuwsbrief`: `aria-current="page"` + `nav-link--active` class (matches Phase 2 active state pattern)
3. No new tab — internal navigation

### RevealOnScroll Stagger on Article Cards

Cards animate in with `delay={i * 80}` (0ms, 80ms, 160ms for first 3 cards). Reduced-motion: animation disabled via existing `prefers-reduced-motion` guard in `RevealOnScroll.astro` — cards render without animation.
