# Quick Task — Levendigheid iteratie 2 (sevora-accenten)

Vervolg op [[260824-liv]]. De meer uitgesproken scroll-effecten die de klant
noemde: pinned moment, kinetische koppen, hero die op scroll reageert.

## Aanpak (alles CSS-only, dubbel afgeschermd; geen JS/layout-risico)

1. **Timeline — pinned header** (desktop ≥1000px): `.tl__head` wordt
   `position: sticky` met opaque navy achtergrond, zodat kop + kerncijfers in
   beeld blijven terwijl de mijlpalen eronder langsscrollen. Valt op oudere
   browsers netjes terug naar normale flow.
2. **Timeline — zelfvullende gele rail**: `.tl__rail-fill` scaleY 0→1 gekoppeld
   aan scroll (view()), geeft voortgangsgevoel door het verhaal. Standaard
   collapsed → op niet-ondersteunde browsers/reduced-motion enkel de grijze rail.
3. **Kinetische koppen** (`.kin`): korte gele accentstreep die zichzelf tekent
   onder de kop bij binnenkomst. Toegepast op Samenwerken- en Timeline-kop.
4. **Hero-foto parallax**: `.hero__parallax`-wrapper schaalt/drift subtiel op
   page-scroll (scroll(root)); gescheiden van de load-reveal op de foto zelf,
   dus geen conflict en geen fullbleed-randgat.

## Verificatie

- `npx astro check` → 0 errors; `npm run build` → 16 pagina's.
- Homepage-screenshot: layout intact, geen overflow/regressie (sticky + scroll-
  effecten tonen zich alleen tijdens echt scrollen).
- Push + deploy direct (verzoek klant).
